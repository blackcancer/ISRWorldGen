# Gabarit de complément de l’inventaire environnemental — 1.4

**Ne remplace pas l’inventaire existant. À utiliser pour compléter les lignes ou champs manquants.**

| Champ | Valeur à documenter |
|---|---|
| Identifiant et famille | Code stable ; minimum V1 / enrichissement optionnel / hors périmètre. |
| Producteur | Lot, contrat, chemin/symbole réel, commit et preuve réellement disponible. |
| Export | Export existant / projection D à créer / producteur encore manquant. |
| Unité/repère/dimension | Coordonnées exactes, unité, résolution/précision, emprise et conditions. |
| Validité | Planifié / initial généré / observé à une date réellement mesurée ; pas de faux état courant. |
| Coverage/absence | Signification de KnownAbsent, NotRecorded, Unsupported, LegacyMissing et autres erreurs. |
| Persistance | Source canonique durable ou reconstruction historiquement exacte, clé/version et propriétaire. |
| Requête | Opération C13 et limites ; preuve de réponse depuis un consommateur à fournir. |
| Contrôle futur | Présence actuelle, accès/espèce, innocuité, consommation : responsabilité du consommateur. |

Une lacune sur un champ minimal doit être suivie jusqu’à D/E/F ; une lacune d’enrichissement facultatif peut rester documentée sans nouvelle simulation. Ne pas transformer une colonne remplie en preuve d’implémentation.
