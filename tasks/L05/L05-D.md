# L05-D — Adopter le plan et auditer les contrats publiés
**Sous-lot délégable · ajout 1.2 · un propriétaire · aucune progression présumée.**

## Objectif
Établir la baseline réelle, fusionner la révision documentaire et classifier les impacts, sans déclarer les anciens lots refaits.

## Livrables
Rapport de migration, matrice de compatibilité des contrats, plan de requalification et mapping des chemins réels.

## Dépendances et démarrage
Prérequis intégrés et conformes à la version du plan : L05-C. L’ordonnanceur lit le statut réel et le registre complémentaire de requalification ; un DONE historique n’est pas une nouvelle preuve. Ne pas charger récursivement leurs documents.

- `artifacts/plan-adoption/`

Les chemins sont des périmètres logiques hérités du plan. L05-D les mappe aux projets C# réels ; ne pas renommer la solution existante. Les contrats, .csproj, dépendances, registries et code d’un autre module exigent un arbitrage d’intégrateur avec mission limitée. Tout appel API reste hors Core.

## Travail et garde-fous
Mission intégrateur : les écritures des contrats/registry requièrent sa validation explicite. Ne pas déduire tous les lots antérieurs DONE.

Écrire les fixtures/oracles discriminants, comparer l’implémentation existante, réaliser le delta minimal compatible, puis exécuter la recette. Un contrat mutable ou un fallback silencieux n’est pas accepté pour contourner un prérequis. Les étapes nécessitant le jeu réservent l’unique instance de test/MCP ; aucun agent ne déploie dans une partie personnelle.

## Acceptation
Exigences : R05U-01, R05U-02, R05U-03. Tests : T05U-01, T05U-02, T05U-03. Voir [T05U](../../tests/T05U.md). Les probes sur fixtures ne prouvent pas seuls le comportement final du monde ; les cas affectés sont rejoués dans L11-C/L13.

## Passation
Utiliser [HANDOFF](../../templates/HANDOFF.md) : commit/base, fichiers, changements de contrats, API vérifiée, résultats exacts et preuves, défauts restants. Le sous-agent rend sa mission ; l’orchestrateur relit, intègre et poursuit le DAG. Aucun sous-agent ne marque DONE le registre global ni n’annonce une validation non exécutée.
