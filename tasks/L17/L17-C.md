## Travail et garde-fous
L’indépendance logique du pack n’impose pas de déplacer tout le dépôt ; aucune refonte des formes d’arbres en dépendance V1.

Écrire les fixtures/oracles discriminants, comparer l’implémentation existante, réaliser le delta minimal compatible, puis exécuter la recette. Un contrat mutable ou un fallback silencieux n’est pas accepté pour contourner un prérequis. Les étapes nécessitant le jeu réservent l’unique instance de test/MCP ; aucun agent ne déploie dans une partie personnelle.

## Acceptation
Exigences : R17-07, R17-10. Tests : T17-07, T17-10. Voir [T17](../../tests/T17.md). Les probes sur fixtures ne prouvent pas seuls le comportement final du monde ; les cas affectés sont rejoués dans L11-C/L13.

## Passation
Utiliser [HANDOFF](../../templates/HANDOFF.md) : commit/base, fichiers, changements de contrats, API vérifiée, résultats exacts et preuves, défauts restants. Le sous-agent rend sa mission ; l’orchestrateur relit, intègre et poursuit le DAG. Aucun sous-agent ne marque DONE le registre global ni n’annonce une validation non exécutée.
