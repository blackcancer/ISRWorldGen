## Résultat

Le probe `L00BDebugProbeModSystem` est un `ModSystem` serveur seulement. Il inscrit un callback en lecture seule sur `ChunkColumnGeneration`, passe `Terrain`, monde `standard`. Il ne modifie ni blocs, ni cartes, ni configuration, ni données de sauvegarde. Il journalise l'identité du processus/module et les coordonnées des callbacks.

Deux mécanismes sont compilés uniquement en `Debug` et inactifs par défaut :

- une demande d'une colonne de probe, planifiée à `RunGame`, dont le booléen local vaut toujours `false` dans le code normal et n'est passé à `true` que par `debugger_set_variable` pendant T00-03 ;
- une `InvalidOperationException` contrôlée, protégée par un booléen local `false` muté par le débogueur et par un garde `Interlocked` à occurrence unique.

La demande utilise la signature locale vérifiée `LoadChunkColumnPriority(int, int, ChunkLoadOptions)`. Une requête à `(31998,31998)` a entraîné 36 callbacks voisins requis par le moteur avant `OnLoaded` ; il s'agit d'un effet borné dans la seule sauvegarde lab. Aucun code d'exception ni de demande de colonne n'est présent dans le binaire Release.

### Audit API strictement nécessaire

- `IWorldManagerAPI.LoadChunkColumnPriority(int, int, ChunkLoadOptions)` et `ChunkLoadOptions.KeepLoaded/OnLoaded` recoupés avec `VintagestoryAPI.xml` local.

## Risques et blocages

- Le MCP n'offre ni choix explicite du profil de lancement ni attache à un PID. La solution courante dépend donc du profil serveur en première position ; un changement d'ordre doit être détecté avant F5.
- Le MCP masque les frames moteur externes dans `debugger_get_callstack`. La frame du probe, le fichier, la ligne et le module sont bien exposés ; une exigence future imposant les frames moteur nécessiterait une extension MCP.
- L'arrêt `debugger_stop` termine le processus débogué ; il ne remplace pas le test complet de cycle de sauvegarde L00-C/T00-06.
- Une requête de colonne prioritaire peut générer les voisins nécessaires. Le mécanisme est Debug-only, false par défaut, borné à une requête et réservé au lab.
- L'incompatibilité réelle de `EnumWorldGenPass.Done` avec l'inscription locale doit rester connue des futurs lots ; elle ne doit pas être généralisée à d'autres API/passes sans audit.
