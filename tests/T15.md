# T15 — Sols, fertilité et compatibilité agricole

Définitions de recette, non résultats exécutés. Les seuils numériques de distribution se figent avant holdout ; voir [budgets](../registry/distribution-budgets.json). Les tests du jeu exigent la cible auditée, et les performances Release sans debugger.

## T15-01 — Profils de sol sur topographie contrôlée
**Niveau : Unitaire + métamorphique. Exigence : R15-01. État livré : NOT_RUN.**

**Préparer.** Versant érodé, terrasse déposée, marais, sol sec et mêmes pluies sur deux substrats.

**Exécuter.** Calculer les profils et faire varier un facteur à la fois.

**Accepter seulement si.** Réponses attendues du profil signé ; épaisseurs bornées ; marais non automatiquement maximal en fertilité.

**Vérifier l’oracle.** Remplacer la fertilité par 1-distance-rivière : fixture contrastée en échec.

**Preuves.** Commit et environnement réels, seed/profil/version de tous les snapshots, protocole, mesures et résultat PASS/FAIL/BLOCKED/NOT_RUN ; TRX .NET quand applicable, trace/état natif et capture de contrôle pour le jeu.
