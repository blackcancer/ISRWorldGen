# T19 — Scénarios de L19-A

Règles communes et index : [T19](../T19.md). Ce fichier est la définition canonique des scénarios ci-dessous. Aucun test du mod n’est déclaré exécuté par sa présence.

## T19-01 — Périmètre environnemental, pas simulation animale

**Propriétaire : L19-A · exigence : R19-01 · nature : revue documentaire.**

Fixture : Diff et arbre de dépendances du lot.

Oracle positif : Contrôler les responsabilités et les périmètres : A/B/C sans runtime, D/E/F avec support réel ; aucun comportement animalier.

Contrôle négatif : Introduire fictivement une tâche de faim/soif ou interdire tout code D/E : la revue doit refuser ces deux écarts.

Preuves : baseline/versions, commande ou protocole, résultat exact et artefacts référencés dans le worklog ; captures et instrumentation natives pour le runtime, cartes quand la sortie est spatiale.
