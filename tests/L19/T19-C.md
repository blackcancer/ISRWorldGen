## T19-07 — Passation alignée sur le code

**Propriétaire : L19-C · exigence : R19-07 · nature : revue documentaire.**

Fixture : Baseline après D/E et rapports L11/L12.

Oracle positif : Croiser chaque champ déclaré disponible avec un export réel et une preuve ; identifier requalification nécessaire.

Contrôle négatif : Un export manquant présenté comme terminé ou un UNKNOWN systématique pour une famille minimale fait échouer la passation.

Preuves : baseline/versions, commande ou protocole, résultat exact et artefacts référencés dans le worklog ; captures et instrumentation natives pour le runtime, cartes quand la sortie est spatiale.
