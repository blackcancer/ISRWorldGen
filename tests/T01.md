# T01 — Tests principaux : Cœur déterministe et contrats de base

**État initial de tous les cas : NOT_RUN.** Exécuter sur les fixtures déterministes de `registry/fixtures.json` et conserver seed/config/version/commit dans chaque preuve. Les seuils indiqués ici sont des obligations de test, non des mesures déjà obtenues.

## T01-01 — Coordonnées extrêmes
**Niveau : Unitaire + propriétés. Exigence : R01-01.**

**Préparer.** Valeurs −1, 0, 1, frontières, dimensions maximales du profil et voisins hors domaine.

**Exécuter.** Tester aller-retour monde/chunk/local, division plancher et multiplications en mode vérifié.

**Accepter seulement si.** Inverses exacts sur le domaine ; refus des débordements/hors limites ; absence de constante de taille dispersée.

**Preuve.** Résultat structuré PASS/FAIL/BLOCKED, paramètres effectifs et artefacts ciblés ; ajouter TRX pour le test .NET, journal/processus pour le jeu et capture référencée lorsqu’une inspection visuelle est requise. Aucune capture seule ne valide une propriété numérique.

## T01-02 — RNG par domaine
**Niveau : Unitaire. Exigence : R01-02.**

**Préparer.** Vecteurs de référence du RNG, seeds 0, 1, −1 et int.MinValue/int.MaxValue.

**Exécuter.** Répéter, réordonner, ajouter une consommation végétation et comparer hydro/cavernes.

**Accepter seulement si.** Vecteurs identiques et aucune perturbation des autres domaines ; IDs sans collision dans le corpus prévu.

**Preuve.** Résultat structuré PASS/FAIL/BLOCKED, paramètres effectifs et artefacts ciblés ; ajouter TRX pour le test .NET, journal/processus pour le jeu et capture référencée lorsqu’une inspection visuelle est requise. Aucune capture seule ne valide une propriété numérique.
