# T20 — Scénarios d’acceptation de L20

**Définitions uniquement : tous ces scénarios commencent à NOT_RUN dans cette livraison.**

T20 appartient exclusivement à G6, après ISRWorldGen 1.0.0. Les fixtures permettent le développement mais ne remplacent pas les preuves en jeu et avec le pack réel explicitement demandées.

## T20-01 — Barrière après V1

Propriétaire : **L20-A**. Exigence : **R20-01**. Niveau : Revue de lancement. État fourni : **NOT_RUN**.

Méthode : Lire baseline, rapports G0–G5 et dépendances ; tenter une planification sans G5 qualifié.

Oracle : L20 n’est pas lancé avant G5 ; aucune tâche V1 n’en dépend. Cas négatif : statut L13-C seul utilisé malgré gate non qualifiée.

## T20-02 — API et contrats locaux

Propriétaire : **L20-A**. Exigence : **R20-02**. Niveau : Audit technique. État fourni : **NOT_RUN**.

Méthode : Relever versions/symboles réels ; comparer aux appels/propositions utilisés dans l’intégration.

Oracle : Signatures vérifiées, champs internes identifiés comme tels. Cas négatif : accéder à un champ slope imaginaire de TreeGenParams.

## T20-03 — Contexte commun et écotones

Propriétaire : **L20-B**. Exigence : **R20-03**. Niveau : Tests de contrat et fixtures. État fourni : **NOT_RUN**.

Méthode : Fixtures de berge, lisière et versant avec mêmes données partagées ; contrôler unités et origine des valeurs.

Oracle : L’adaptation varie selon le contexte sans changer le sol/climat de référence. Cas négatif : seconde carte climatique incohérente.

## T20-04 — Silhouettes en blocs et obstacles

Propriétaire : **L20-B**. Exigence : **R20-04**. Niveau : Fixtures et revue visuelle. État fourni : **NOT_RUN**.

Méthode : Sur fixtures contrôlées, comparer variantes et branches près d’un relief et d’un obstacle, plus un arbre libre.

Oracle : Identité visuelle conservée et adaptation observable. Cas négatif : option affichée mais aucun effet sur la proposition.

## T20-05 — Déterminisme, limites et chunks

Propriétaire : **L20-B**. Exigence : **R20-05**. Niveau : Propriétés et stress borné. État fourni : **NOT_RUN**.

Méthode : Rejouer mêmes entrées avec ordres/workers différents, limites d’emprise, paramètres invalides et quatre chunks voisins.

Oracle : Même proposition/hash attendu et coût borné. Cas négatif : silhouette dépendant du worker ou boucle sans borne.

## T20-06 — Placement natif et ownership

Propriétaire : **L20-C**. Exigence : **R20-06**. Niveau : Intégration native réelle. État fourni : **NOT_RUN**.

Méthode : Tracer les écritures et initialisations de l’arbre, du sol forestier et du sous-bois, avec structure et passage protégés.

Oracle : Une seule chaîne, aucun double passage ni bloc protégé modifié. Cas négatif : deux appels de sol forestier.

## T20-07 — Sauvegarde et absence de régénération

Propriétaire : **L20-C**. Exigence : **R20-07**. Niveau : Sauvegarde réelle. État fourni : **NOT_RUN**.

Méthode : Générer, jouer/modifier, sauvegarder, recharger et tenter une activation incompatible avec le profil enregistré.

Oracle : Aucun chunk joué réécrit ; incompatibilité traitée explicitement. Cas négatif : replantation après abattage.

## T20-08 — Reproduction de diagnostic

Propriétaire : **L20-D**. Exigence : **R20-08**. Niveau : Outil réel. État fourni : **NOT_RUN**.

Méthode : Exporter le manifeste d’un essai, changer les réglages courants et rejouer le manifeste avec les versions requises.

Oracle : Résultat équivalent à entrées identiques ou incompatibilité explicite. Cas négatif : seed sans version/contexte donnant un autre arbre non signalé.

## T20-09 — Sûreté de l’atelier

Propriétaire : **L20-D**. Exigence : **R20-09**. Niveau : Cas négatifs en monde isolé. État fourni : **NOT_RUN**.

Méthode : Tester aperçu, absence de droit, dépassement de taille, chemin d’export invalide et interruption de placement.

Oracle : Aperçu sans écriture ; erreurs refusées avant mutation ou état partiel explicite et récupérable selon garantie prouvée. Cas négatif : undo annoncé sans restauration des états.

## T20-10 — Matrice du pack réel

Propriétaire : **L20-E**. Exigence : **R20-10**. Niveau : Installations réelles. État fourni : **NOT_RUN**.

Méthode : Exécuter les quatre configurations de S20, identifier pack/version/hash et tester absence/incompatibilité.

Oracle : Pack utilisable sans ISRWorldGen, ISRWorldGen utilisable sans pack sur monde approprié. Cas négatif : référence obligatoire inverse ; un pack synthétique ne remplace pas cette preuve.

## T20-11 — Usages natifs, saisons et budgets

Propriétaire : **L20-E**. Exigence : **R20-11**. Niveau : Parcours réels et performance. État fourni : **NOT_RUN**.

Méthode : Planter, récolter, observer cycles natifs, redémarrer serveur et mesurer CPU/mémoire sur corpus gelé.

Oracle : Usages préservés, budgets respectés en Release. Cas négatif : test mock présenté comme preuve saisonnière ou seuil remonté après échec.

## T20-12 — Paysages et intérêt d’exploration

Propriétaire : **L20-E**. Exigence : **R20-12**. Niveau : Revue visuelle indépendante. État fourni : **NOT_RUN**.

Méthode : Comparer native/améliorée sur contexte et seeds figés ; examiner silhouettes, peuplements régionaux et jonctions.

Oracle : Différences justifiées et lisibles, sans verger/couture ni essences promises mais absentes. Cas négatif : seed choisie après examen du holdout pour masquer les défauts.

## Preuves

Chaque rapport nomme le commit, les versions, les entrées, la méthode réellement exécutée, le résultat et ses limites. Pour un test runtime : seed, profil, monde de test, ordre/workers, commandes et artefacts ; pour une revue : références contrôlées, échantillon et cas négatifs. Un test non exécuté reste NOT_RUN ; les preuves historiques ne sont jamais écrasées.
